# 🤖 AI Resume Screening System

## 🚀 Project Overview
The AI Resume Screening System is a machine learning-based application designed to automatically analyze and classify resumes based on job requirements. It helps recruiters quickly filter and shortlist candidates by evaluating resume content using Natural Language Processing (NLP).

---

## ✨ Features
- 📄 Resume parsing and text extraction
- 🧠 NLP-based feature extraction (TF-IDF)
- 🎯 Resume classification using Machine Learning models
- 📊 Candidate ranking based on relevance score
- ⚡ Fast and automated screening process
- 💻 User-friendly interface for uploading resumes

---

## 🛠️ Tech Stack
- Python
- Machine Learning (Scikit-learn)
- Natural Language Processing (NLP)
- Pandas, NumPy
- Flask (for backend)
- HTML, CSS, JavaScript (for frontend)

---

## ⚙️ How It Works
1. Upload resume (PDF/Text)
2. Extract text from resume
3. Preprocess text (cleaning, stopword removal)
4. Convert text into numerical features using TF-IDF
5. Apply trained ML model to classify or rank resumes
6. Display results with score and recommendations
